## Mandatory proof before activating a provider

1. Written coverage matrix by Turkish sport, league and season: schedule, result, lineup, event timeline, shots, cards, possession, advanced metrics and delivery latency.
2. Commercial permission to **display and cache** data via website and iOS/Android, create AI-authored original news **derived from statistics**, and present attributions as required.
3. Separate license/permission for official club crests, player likenesses, match photos and competition trademarks.
4. Measured API quota, outage behavior, refresh strategy, retention and territory restrictions.
5. Budget, signed agreement reference, renewal/expiry, vendor support and revocation process.
6. Actual credentialed API probe and a captured example fixture for every must-have sport/competition.

## Blocking rule

No provider-specific API adapter or production publication is activated until the contracts are approved. Public endpoint access is not sufficient legal permission. No scraping of Maçkolik or other sites without appropriate authorization.
